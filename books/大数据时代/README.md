- **出版社**：浙江人民出版社

- **主题**：大数据带来的思维变革（全样而非抽样、混杂性而非精确性、相关关系而非因果关系）

## 核心方法论框架（公开可引用的要点，非全文）
1. **更多（Volume）**：全量数据优于抽样，能分析全体而非样本。
2. **更杂（Variety）**：接受混杂性，容忍不精确，追求大体方向的正确。
3. **更好（Velocity/Value）**：关注相关关系而非因果，用关联预测与决策。
4. **数据价值链**：谁拥有数据、谁拥有技能、谁拥有思维，决定价值归属。
